1. Resumen Ejecutivo

Se desarrollo, endurecio (hardened) y se despliega parcialmente una aplicacion web Python/Flask integrando la herramienta SAST Bandit para analisis estatico de codigo fuente. El proyecto cumple todos los requisitos academicos: repositorio publico GitHub, pipeline automatizado GitHub Actions, doble escaneo de seguridad (previo y posterior a remediacion) y despliegue automatico en proveedor SaaS publico (Render.com) conectado directamente al repositorio.

Bandit fue seleccionado expresamente por ser distinto de Semgrep (utilizado en los labs del curso). Bandit aparece listado tanto por OWASP (Source Code Analysis Tools) como por el NIST (Source Code Security Analyzers) como analizador SAST valido para proyectos Python.

4. Automatizacion - Pipeline GitHub Actions

El workflow se define en .github/workflows/security-scan.yml y se ejecuta automaticamente en cada push y pull request contra main/master, ademas de poder lanzarse manualmente via workflow_dispatch.

Disparadores (triggers)

EventoRamaCuando se ejecuta
pushmain / masterCada vez que se sube codigo
pull_requestmain / masterCada PR abierto o actualizado
workflow_dispatch-Manual desde la pestana Actions

6. Remediacion Aplicada (7 hallazgos → 2)

HallazgoCorreccion implementada
B602 (HIGH) shell=True Command Injection ANTES: subprocess.run(command, shell=True)
DESPUES: shell=False + shlex.split(cmd_input) + timeout=5 anti-DoS + markupsafe.escape() sobre la salida.
B324 (HIGH) MD5 algoritmo roto ANTES: hashlib.md5(...)
DESPUES: hashlib.sha256(...) (FIPS 140 compatible).
B301 (MEDIUM) pickle.loads / RCE Se ELIMINO completamente modulo pickle.
DESPUES: json.loads() (nunca ejecuta codigo arbitrario).
B104 (MEDIUM) bind 0.0.0.0 + debug ANTES: host='0.0.0.0', debug=True
DESPUES: host=os.environ.get('HOST','127.0.0.1'), debug=False, port via env.
B105 (LOW) hardcoded password ANTES: literal en fuente
DESPUES: os.environ.get('ADMIN_PASSWORD','') (12-Factor).
B403 (LOW) import pickle Resuelto como efecto colateral al reemplazar pickle por JSON.
Bonus XSS Reflected Toda salida derivada de entrada del usuario (/greet, /run, /hash, /load) pasa por markupsafe.escape() (HTML entity encoding).

Nota primer deploy fallido

El deploy inicial dio status 127 (command not found) por dos razones: (1) Render detecto indebidamente Poetry como gestor (lo corrije runtime.txt + Procfile ya subidos) y (2) el Build Command fue guardado con comillas simples literales en la UI de Render. Solucion: desde Settings -> Build & Deploy pegar ambos comandos sin comillas y luego Manual Deploy -> Deploy latest commit.
